# 성과 작성 지침

이 파일은 업무를 묶고 강조하고 표현하는 방식을 정한다. 아래의 초기값은 사용자 피드백으로 바꾼다. 사실·기간·기여 귀속·근거 검증은 분석 프롬프트의 규칙을 따른다. 예시 문장은 실제 업무 기록이 아니다.

## 목적과 독자

- 초기값: 본인의 기간별 업무 회고와 성과 초안 작성.
- 제출 대상과 평가 체계: 아직 지정하지 않음. 특정 조직의 평가 항목이나 등급을 가정하지 않는다.

## 분류

- 초기값: 실제 데이터에서 드러나는 업무 주제로 분류한다.
- 선호 카테고리: 사용자 피드백으로 추가한다.
- 분류가 겹치면 주된 산출물 기준으로 한 곳에 두고 관련성을 설명한다.

## 업무 묶기

- 같은 목표·산출물에 기여한 티켓은 한 성과로 묶는다.
- 같은 프로젝트에 속한다는 이유만으로 서로 다른 결과를 합치지 않는다.
- 반복 업무는 반복 사실과 확인된 건수·범위를 함께 요약한다.
- 사용자가 별도로 드러내고 싶은 활동: 피드백으로 추가한다.

## 강조할 가치

- 초기값: 해결한 문제, 만든 산출물, 본인의 구체적 역할을 우선한다.
- 우선 강조할 가치: 사용자 피드백으로 정한다.
- 기술 난도, 업무 중요도, 조직 영향은 자료에서 확인되는 범위에서 설명한다.

## 문장 구성

- 기본 순서: 문제 또는 목표 → 내 행동 → 산출물 → 확인된 효과.
- 초안은 구체적인 동사를 사용하고 한 문장에 한 핵심 기여를 담는다.
- 효과를 확인하기 어려우면 수행 내용과 산출물만으로 완결한다.

## 완료와 진행 중

- 완료: 기간 내 완성된 본인 산출물과 결과를 기술한다.
- 진행 중: 기간 내 수행한 단계·검증·중간 산출물과 기록에 있는 잔여 작업을 기술한다.
- 열린 티켓의 일부 산출물이 완료된 경우 해당 범위와 전체 진행 상태를 함께 쓴다.

## 문체와 분량

- 초기값: 한국어, 간결하고 사실적인 업무 보고 문체.
- 성과별 핵심 문장 1~3개를 기본으로 하고 필요한 근거를 붙인다.
- 1인칭 사용, 명사형/서술형 종결, 전체 길이: 사용자 피드백으로 조정한다.
